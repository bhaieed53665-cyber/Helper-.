# بوت التذاكر - Melaad Support

## التشغيل محلياً (اختياري، للتجربة بس)

```bash
pip install -r requirements.txt
export BOT_TOKEN="التوكن"
python bot.py
```

## الرفع على Railway

1. سوي مشروع جديد على https://railway.app واختار **Deploy from GitHub repo** (ارفع هاي الملفات الثلاث `bot.py` و `requirements.txt` و `Procfile` على مستودع GitHub وربطه)، أو استخدم **Empty Project** ثم ارفع الملفات مباشرة عن طريق Railway CLI.
2. بعد ما يتعرف المشروع، روح لتبويب **Variables** وضيف المتغيرات التالية (Environment Variables):

| اسم المتغير | القيمة |
|---|---|
| `BOT_TOKEN` | توكن البوت من https://discord.com/developers/applications |
| `GUILD_ID` | آيدي سيرفرك (اختياري - لو حطيته الأوامر السلاش بتظهر فوراً) |
| `TICKET_CATEGORY_ID` | آيدي الكاتيغوري يلي بدك التذاكر تنفتح جواته (لازم) |
| `PANEL_IMAGE_URL` | رابط مباشر لصورة "Melaad Support" |
| `STAFF_ROLE_ID` | (اختياري، القيمة الافتراضية 1535668575585566871) |
| `SPECIAL_ADMIN_ID` | (اختياري، القيمة الافتراضية 920981254554406952) |
| `TICKET_ICON_EMOJI` | (اختياري) إيموجي زر فتح التذكرة، مثال: `<:ticket:123456789012345678>` |
| `CLAIM_EMOJI` | (اختياري) إيموجي زر الاستلام |
| `DELETE_EMOJI` | (اختياري) إيموجي زر الحذف |

3. Railway بيلتقط ملف `Procfile` تلقائياً وبيشغل البوت كـ **worker** (مو web service، لأنه بوت ديسكورد مالوش سيرفر HTTP).
4. بعد ما تضيف المتغيرات، اعمل **Deploy** وتابع اللوغز (Logs) لحد ما تشوف رسالة "تم تسجيل الدخول كـ ...".

### ملاحظة مهمة بخصوص PANEL_IMAGE_URL
لازم يكون رابط مباشر للصورة (ينتهي بامتداد الصورة أو يفتح الصورة مباشرة بالمتصفح). ارفع الصورة بأي روم بالسيرفر، اضغط عليها يمين واختار نسخ الرابط.

### ملاحظة بخصوص الإيموجيات
حطيتلك إيموجيات افتراضية (🎫 🔒 🗑️) عشان يشتغل البوت مباشرة بدون ما تعبي شي إضافي. اذا بدك نفس شكل الأيقونات يلي بعتلي ياهن بالضبط، ارفعهن كـ Custom Emoji بالسيرفر وحط قيمتهن بمتغيرات `TICKET_ICON_EMOJI` / `CLAIM_EMOJI` / `DELETE_EMOJI` بصيغة `<:name:id>`.

## صلاحيات البوت المطلوبة (Bot Permissions)
- Manage Channels
- View Channels
- Send Messages
- Embed Links
- Read Message History

لما تعمل انفايت للبوت لازم تفعّل صلاحية `Manage Channels` عشان يقدر ينشئ رومات التذاكر. وتحت **Privileged Gateway Intents** بصفحة الـ Bot على Discord Developer Portal، فعّل **Server Members Intent** (لأن الكود بيستخدم `intents.members`).

## شو سوى البوت بالضبط

- أمر `/panel` يرسل اللوحة بنفس الروم يلي انكتب فيه الأمر، ومحصور بالأدمنستريتر فقط.
- اللوحة = صورة فقط + زر واحد بدون أي كتابة عليه.
- الزر يفتح للشخص (بشكل خاص/ephemeral) قائمة اختيار فيها 4 خيارات بدون إيموجيات: استفسار، شكوى، مساعدة، رتب خاصه.
- عند اختيار "رتب خاصه": التذكرة تنفتح خاصة للشخص صاحب الآيدي `920981254554406952` فقط (ما حدا من الستاف تيم يشوفها).
- عند اختيار أي خيار تاني: التذكرة تنفتح للشخص + رتبة الستاف تيم (`1535668575585566871`).
- بكل الأنواع الأربعة: أول رسالة بالتذكرة فيها منشن `Staff Team | @الشخص`، وتحتها صورة Melaad Support مع نص "اهلا وسهلا, يرجى كتابة الموضوع وسيتم الرد من قبل المسؤولين"، وتحتها زرين بدون كتابة (استلام / حذف).
- زر "استلام": يعطل نفسه بعد الاستلام ويعلن مين استلم.
- زر "حذف": يحذف الروم بعد 5 ثواني (فيه رسالة تنبيه قبل الحذف). محدود بالستاف تيم/الأدمن، وبتذكرة "رتب خاصه" محدود بالأدمن صاحب الآيدي بس.

## ملاحظة
حطيت رسالة تنبيه بسيطة "جاري حذف التذكرة خلال 5 ثواني..." وتأكيد فتح التذكرة "تم فتح تذكرتك هون" — هاي مش مذكورة بالتفصيل بطلبك، بس ضرورية لتجربة استخدام سليمة. إذا بدك تشيلهم أو تغير النص، قولّي.
